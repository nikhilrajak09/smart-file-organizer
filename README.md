# smart-file-organizer
Python automation project to organize files by type

A Python automation project that organizes files in a directory
into folders based on their file types such as Images, Documents,
Audio, and Videos.

## Features
- Automatically scans a folder
- Creates folders if they do not exist
- Organizes files based on file extensions
- Beginner-friendly and real-world use case

## Technologies Used
- Python
- OS module
- Shutil module

## How to Run
1. Place mixed files in a folder
2. Update the folder path in the script
3. Run the script:
   python file_organizer.py

## Demo
The script was tested on a demo folder containing mixed file types
and successfully organized them into respective folders.
